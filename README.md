# Orings — O型環設計 App

Android App（Kotlin + Jetpack Compose），用來計算 O 型環溝槽的壓縮率、拉伸率、填充率，並推薦溝槽尺寸。

## 專案結構

另有網頁版：`web/index.html`（直接用瀏覽器開啟即可，不需安裝），計算邏輯與 `core` 一致。

| 模組 | 內容 | 建置需求 |
|---|---|---|
| `core/` | 純 Kotlin 計算核心＋單元測試 | 只需 JDK 17+ |
| `app/` | Android Compose 介面 | Android SDK（用 Android Studio 開啟即可） |

沒有 Android SDK 的環境會自動略過 `:app`，只建置 `:core`。

## 下載

- **Android App**：到 [Releases](https://github.com/rboneone-png/Orings/releases) 下載最新的 `orings-vX.Y.Z.apk`
- **網頁版**：https://rboneone-png.github.io/Orings/

發佈新版本：在 Actions 頁面執行「Release APK」並輸入版本號，或推送 `v*` 標籤。

> 從 v0.4.1 起 APK 使用專案內固定的除錯簽章（`app/debug.keystore`），之後的版本都能直接覆蓋更新。
> v0.4.0 以前的版本每次簽章都不同，第一次升級到 v0.4.1 需先解除安裝舊版。

## 開始

1. 用 Android Studio 開啟本資料夾（會自動建立 `local.properties`），按 Run。
2. 只測試計算核心：

```bash
./gradlew :core:test
```

## 計算公式（百分比以小數表示）

- 拉伸率 = (套入直徑 − ID) ÷ ID
- 有效線徑 = CS ÷ √(1 + 拉伸率)（體積守恆近似）
- 壓縮率 = (有效線徑 − 溝槽深度) ÷ 有效線徑
- 填充率 = 有效截面積 ÷ (溝槽深度 × 溝槽寬度)

預設建議範圍（`DesignLimits`）：

| 條件 | 壓縮率 | 拉伸率 | 填充率 |
|---|---|---|---|
| 靜態徑向 | 15–30% | ≤ 5% | ≤ 85% |
| 靜態端面 | 20–30% | ≤ 5% | ≤ 85% |
| 動態 | 10–20% | ≤ 3% | ≤ 85% |

> 以上是一般工業經驗值，實際設計請依材質廠商型錄確認。

## 標準尺寸表

| 標準 | 範圍 | 筆數 |
|---|---|---|
| AS568 | -001 ~ -475，-901 ~ -932（接頭埠口用，不列入推薦） | 369 |
| JIS B2401 P（運動用） | P3 ~ P400 | 122 |
| JIS B2401 G（固定用，不推薦用於動態） | G25 ~ G300 | 56 |

- `SizeCatalog.search()`：依代號或內徑搜尋
- `SizeCatalog.suitableFor()`：輸入密封型式與配合直徑，列出每種線徑最合適的尺寸並附推薦溝槽

> 尺寸數值依標準規則整理，正式使用前請與 SAE AS568 / JIS B2401 原文或廠商型錄核對。

## 硬度與擠出

`Extrusion.recommend(壓力 MPa, 擠出間隙 mm)` 依擠出極限從 70A / 80A / 90A 中選最軟且撐得住的硬度，超過 90A 極限則建議加擋圈（上限 35 MPa）。
溝槽計算傳入 `Operating` 後會另外檢查：擠出極限、擋圈佔用的溝槽寬度、90A 在低壓或高壓縮率時的警告。

> 擠出極限為一般經驗值（靜態、室溫），正式設計請以廠商擠出曲線為準。

## O型環設計（已知溝槽反推）

`RingDesigner.design(溝槽, …)` 依目標壓縮率與拉伸率反推理想的內徑與線徑，並依合適程度列出標準尺寸。

## 熱膨脹修正

`Thermal.analyze(O 型環, 溝槽, ThermalInput, …)` 把 O 型環與溝槽各自依膨脹係數換算到組裝溫度（20°C）、最低溫、最高溫，分別檢查壓縮率、拉伸率、填充率。

- O 型環膨脹係數依材質（NBR 1.3、FKM 1.6、VMQ 2.5、FFKM 2.3 ×10⁻⁴/°C 等），未選材質時以 NBR 計算
- 金屬件：碳鋼、不鏽鋼、鋁合金、黃銅、鑄鐵、鈦合金
- 推薦溝槽時會用實際高溫填充率回推寬度，確保最高溫時填充率 ≤ 80%

> 膨脹係數為一般手冊近似值；未考慮低溫硬化、介質膨潤與壓縮永久變形。

## 表面粗糙度

`SurfaceFinish.recommend(使用條件, 嚴格)` 給出配合面、溝槽底面、溝槽側面的 Ra／Rz 建議（µm）：

| 條件 | 配合面 | 溝槽底面 | 溝槽側面 |
|---|---|---|---|
| 靜態 | Ra ≤ 1.6（Rz ≤ 6.3） | Ra ≤ 1.6 | Ra ≤ 3.2 |
| 靜態，壓力脈動／氣體或真空 | Ra ≤ 0.8（Rz ≤ 3.2） | Ra ≤ 1.6 | Ra ≤ 1.6 |
| 動態 | Ra 0.1–0.4（Rz ≤ 1.6，Mr > 50%） | Ra ≤ 1.6 | Ra ≤ 3.2 |

> 一般密封件廠商設計指引的經驗值，正式設計請以廠商型錄為準。

## 單位

計算核心一律用 mm；`LengthUnit`（mm / inch）只負責輸入解析與顯示。App 切換單位時會把已輸入的數值一起換算。

## 材質選擇

`MaterialAdvisor.evaluate(最低溫, 最高溫, 接觸介質, 使用條件)` 會評估 9 種材質：
NBR、HNBR、FKM、EPDM、VMQ、FVMQ、CR、AU、FFKM。

- 排除：溫度超出範圍、介質評等「不建議」、動態使用但材質不耐磨（VMQ、FVMQ）
- 排序：耐受性 → 溫度餘裕 → 相對成本（便宜夠用的優先）

> 溫度與耐受性為一般工業經驗值，正式選用請以廠商型錄為準。
